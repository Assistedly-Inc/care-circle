# Care Circle — Cloudflare Deployment Guide

## Quick Start

```bash
# Install Wrangler (if needed)
npm install -g wrangler

# Login
npx wrangler login

# Deploy to Cloudflare Pages
npx wrangler pages deploy out
```

## Development

```bash
npm run dev
```

## Features
- Cloudflare Pages for hosting
- Next.js 14 (App Router)
- Tailwind CSS
- Prisma for database
